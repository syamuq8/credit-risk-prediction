{% if page_key == 'faq' %}

The prediction engine utilizes a Gradient Boosting or XGBoost Classifier trained on historical applicant records. It measures credit profiles (FICO score, previous defaults) against financial metrics (DTI ratio, income, savings margin) to calculate the mathematical probability that an applicant will fail to repay.

The DTI ratio represents the portion of an applicant's monthly income that is allocated to paying outstanding debts (credit cards, existing loans, proposed EMI). A DTI ratio exceeding 43% is generally flagged as high-risk, as it leaves minimal buffer for unexpected living expenses.

The Model Center saves separate serialized files for all trained classifiers (Logistic Regression, Decision Trees, Random Forests, XGBoost, SVM, and Gradient Boosting). When an admin activates a different model, the global Flask server releases the previous classifier from memory and binds the new model to live predictions instantly.

Applicants can reduce default risk by paying off credit card balances (which lowers their credit utilization and improves DTI), increasing savings margins, maintaining employment tenure, and avoiding applying for multiple concurrent loans.

Project Overview

The Credit Risk Prediction System is built as a complete final-year machine learning research application. It combines custom data preprocessing, multi-model evaluation benchmarking, explainable AI explanations (local feature attributions), and secure record management to build a professional fintech decision support dashboard.
